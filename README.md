# Windows IT Deployment – Group Policy & PowerShell

## Overview
This project demonstrates improvements to Windows endpoint deployment using Group Policy for shared printer mapping and PowerShell to automate Sophos endpoint-security installation.

## What I Did
- Configured shared printer mapping through Group Policy.
- Replaced a batch-file approach that did not work as expected with a PowerShell startup installation workflow.
- Tested printer mapping and software installation across five Windows devices.
- Removed company-specific information from the portfolio example.

## Results
- Successfully tested on **5 devices**.
- Printer mapping and software installation worked as expected.
- Reduced reported setup time from almost 20 minutes to around 10 minutes — approximately **50% less time**.
- Reduced repetitive manual setup tasks.
